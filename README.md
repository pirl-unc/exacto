# Exacto

Expression Quantification and Identification of Augmented Transcripts of Somatic Variant Origin

## 01. Dependencies
- python3 (3.9 tested)
- pandas
- pysam
- pyvcf
- pyensembl

## 02. Installation
```
pip install .
```

## 03. Packaging
```
python -m build
```

## 04. Testing
```
bash lint.sh
bash unittest.sh
```
