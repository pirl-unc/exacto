Command Line Interface 

usage: exacto [-h] [--version] {refine,annotate,merge} ...

Exacto: EXtracting And Counting Transcripts in Oncology.

positional arguments:
  {refine,annotate,merge}
                        Exacto sub-commands.
    refine              Refine variants.
    annotate            Annotate variants.
    merge               Merge variants.

optional arguments:
  -h, --help            show this help message and exit
  --version, -v         show program's version number and exit

Exacto includes the following main commands:

  • simulate_variants (simulates DNA and RNA variants)

Exacto also includes the following accessory commands:

  • simulate_variants (simulates DNA and RNA variants)
  • refine (refines DNA or RNA variants)
  • merge (merges DNA or RNA variants)
  • annotate (annotates DNA or RNA variants)

simulate_variants

This command simulates a list of random DNA and RNA variants.

usage: exacto.py simulate [-h] 
  --nucleic_acid {dna,rna} 
  --target_regions_tsv_file TARGET_REGIONS_TSV_FILE
  --variants_tsv_file VARIANTS_TSV_FILE 
  --clones_tsv_file CLONES_TSV_FILE 
  --reference_genome_fasta_file REFERENCE_GENOME_FASTA_FILE 
  --base_error_rate BASE_ERROR_RATE 
  --indel_error_rate INDEL_ERROR_RATE 
  --indel_error_size_mean INDEL_ERROR_SIZE_MEAN 
  --read_length_mean READ_LENGTH_MEAN 
  --read_length_stdev READ_LENGTH_STDEV 
  --target_throughput TARGET_THROUGHPUT
  --base_score_beta_dist_alpha BASE_SCORE_BETA_DIST_ALPHA 
  --base_score_beta_dist_beta BASE_SCORE_BETA_DIST_BETA 
  --num_threads NUM_THREADS
  --output_fastq_gz_file OUTPUT_FASTQ_GZ_FILE 
  [--gtf_file GTF_FILE]
Required Parameter Description
--nucleic_acid Nucleic acid type (‘dna’ or ‘rna’).
--target_regions_tsv_file List of genomic regions to simulate. TSV file with the following columns:
• chr
• start
• end
--variants_tsv_file List of variants to simulate. TSV file with the following columns:
• chr_1
• pos_1
• chr_2
• pos_2
• variant_type
• clone_id

Values in chr_1 and chr_2 must match the contig names in --reference_genome_fasta_file

Note that for SNVs, keep the values for chr_2 and pos_2 the same as chr_1 and pos_2, respectively.

The column variant_type should be one of the following types:
• SNV
• INS
• INV_5to5
• INV_5to3
• INV_3to3
• TANDEM_DUP
• SEG_DUP
• TRA
• SPVAR
• IR
• CIRC_RNA
• ERV
• HLA_VAR
--clones_tsv_file List of clones to simulate. TSV file with the following columns:
• clone_id
• proportion (a value between 0.0 and 1.0).

In genomic regions where there is no variant specified in variants_tsv_file, Exacto will simulate reads based on the reference genome. Note that if you specify reference for the clone_id, Exacto will simulate reads based on the reference genome.
--reference_genome_fasta_file Reference genome FASTA file.
--base_error_rate Recommended value for simulating Pacific Biosciences HiFi CCS reads: 0.0009

\(\text{error rate} = \frac{FP+FN}{TP+FP+FN+TN}\)

Based on Wenger et al., Nature Biotechnology 2019:
precision \(= \frac{TP}{TP+FP} = 0.9991\)
recall \(= \frac{TP}{TP+FN} = 0.9991\)

Assume:
TN \(= 1,000,000\)
TP \(= 1,000,000\)
Then:
FP \(\approx 901\)
FN \(\approx 901\)
\(\therefore\) error rate \(= 0.0009\)
--indel_error_rate Recommended value for simulating Pacific Biosciences HiFi CCS reads: 0.0402

\(\text{error rate} = \frac{FP+FN}{TP+FP+FN+TN}\)

Based on Wenger et al., Nature Biotechnology 2019:
precision \(= \frac{TP}{TP+FP} = 0.9598\)
recall \(= \frac{TP}{TP+FN} = 0.9598\)

Assume:
TN \(= 1,000,000\)
TP \(= 1,000,000\)
Then:
FP \(\approx 41,884\)
FN \(\approx 41,884\)
\(\therefore\) error rate \(= 0.0402\)
--indel_error_size_mean INDEL error size mean (\(=\frac{1}{\lambda}\)).
INDEL error size sampled from an exponential probability density function:
\(\lambda e^{-\lambda x}\)
--read_length_mean Simulated sequencing read length mean. Recommended value for simulating Pacific Biosciences HiFi CCS reads: 17,500. The read length is modeled as a log-normal distribution.
--read_length_stdev Simulated sequencing read length standard deviation. Recommended value for simulating Pacific Biosciences HiFi CCS reads: 3,000. The read length is modeled as a log-normal distribution.
--target_throughput Target throughput in gigabases (default: 90). Simulating 90 gigabses (Gb) for the human genome (3 Gb) will result in approximately 30x coverage.
--base_score_beta_dist_alpha Alpha (shape 1) value of beta distribution for sampling base quality score (Phred33) value. Recommended value for simulating Pacific Biosciences HiFi CCS reads: 0.400.
--base_score_beta_dist_beta Beta (shape 2) value of beta distribution for sampling base quality score (Phred33) value. Recommended value for simulating Pacific Biosciences HiFi CCS reads: 1.526.
--num_threads Number of threads to use.
--output_fastq_gz_file Output fastq.gz file.
Optional Parameter Description
--gtf_file Please specify this parameter if ‘nucleic_acid’ is ‘rna’.
